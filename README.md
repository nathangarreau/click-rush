# Click Rush app

Score and learn companion for **Click Rush**, the web traffic board game (English Game 2026, team Click Rush, MyDigital School Angers).

Open it: https://nathangarreau.github.io/click-rush/

- Track coins, visitors, customers and the ranking each month
- Black Hat cards: cost, visitors and Google audit
- Learn: what every card means in real digital marketing (SEO, SEA, CPC, CPM, GDPR...)
